# Herdr Relay agent instructions

## Agent skills

### Issue tracker

Track issues and specs in `hackerchai/herdr-relay` GitHub Issues. Before reading or publishing tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before triaging or changing triage labels, read `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout: root `CONTEXT.md` and `docs/adr/`. Before domain exploration or terminology/decision changes, read `docs/agents/domain.md`.
