# Ticket #1: local Rust CLI acceptance

Date: 2026-10-10. Environment: macOS 27.0 arm64, Rust/Cargo 1.99.0,
official Herdr 0.9.3 (`5173a3e0ae42d5d1ab7ebfa5d5e6329f7c3d23f8e1a3677c7ce3231da2884157`).
The installed Herdr 0.8.2 was not replaced.

The implementation provides `herdr-relay local --session <name>` or an explicit
`--socket`, with optional `--herdr` and `--herdr-config-dir`. Session spelling
is exact even on a case-insensitive filesystem. Native socket type, ownership,
directory safety, writable permissions, symlinks and peer credentials are
checked. Instance replacement is detected using the socket device/inode.
An OS advisory lock prevents two Relay processes from attaching to the same
socket inode; direct Herdr connections are outside this constraint.

## Necessary automated tests

Eight module-boundary tests passed with `cargo test --locked`:

- Explicit session selection does not fall back to the default instance.
- Invalid/traversing names are rejected.
- Non-sockets, user symlinks and sockets writable by other users are rejected.
- Session spelling is exact on case-insensitive filesystems.
- A second reservation is busy until the previous reservation is dropped.
- Opaque bytes, including a 512 KiB payload, cross the bounded stream; closing
  either end terminates the channel instead of retaining a half-open session.
- A silent native server hits the handshake deadline.
- Terminal flags are restored after a client dies in raw mode.

Each tested behavior was observed failing before its implementation/fix.
Formatting and `cargo clippy --all-targets --locked -- -D warnings` also passed.
No automated e2e suite was added, following the maintainer's updated testing
instruction.

## Manual real-client checks

A dedicated Herdr `work` session ran under a temporary XDG configuration at
`/tmp/hr-manual-0cxxulnx`. The CLI launched the official `herdr client` in a PTY;
commands were entered interactively through that client. Its server PID was
7236 and its pane shell PID was 7517 during this run.

| Check | Observed result |
|---|---|
| Conflicting inherited `HERDR_SESSION`, `HERDR_SOCKET_PATH`, `HERDR_CLIENT_SOCKET_PATH` | The explicitly selected `work` instance opened successfully |
| Native keyboard and screen update | `printf 'RELAY_OK_中文_🙂\n'` displayed the expected Unicode output |
| Resize | Resizing the client PTY from 24×80 to 40×120 changed pane `stty size` from `23 53` to `39 93` (Herdr sidebar/tab chrome consumes rows/columns) |
| Simultaneous second attach | Returned `TARGET_BUSY`; first client continued operating |
| Normal detach, `Ctrl+B` then `Q` | CLI exit 0; before/after `stty -g` identical |
| SIGTERM to the Relay CLI | `CANCELLED`, CLI exit 130; native client reaped; before/after `stty -g` identical |
| SIGKILL to the owned native client | `NATIVE_CLIENT_FAILED`, CLI exit 1; before/after `stty -g` identical after the fix below |
| Server/pane survival | PIDs 7236 and 7517 remained alive after normal detach, cancellation and client kill; reattachment worked |
| Missing session | `TARGET_OFFLINE`, with no fallback or server launch |
| Existing Herdr 0.8.2 selected as client | `INCOMPATIBLE_HERDR` before client startup |
| Missing Herdr executable | `CLIENT_START_FAILED` |

The manual failure path exposed a macOS `PENDIN` difference after restoring raw
mode with `TCSANOW`. A minimal PTY regression reproduced the same difference.
Using `TCSAFLUSH` clears pending input and restores the original flags; both the
unit regression and the original real-client SIGKILL check then passed.
Abnormal termination also resets the display modes enabled by Herdr 0.9.3.

After verifying server survival, the dedicated test server was explicitly
stopped through its named-session CLI. No user's existing Herdr instance was
stopped. The native UI was exercised through a PTY, not through a graphical
terminal screenshot; graphics/clipboard capabilities remain ticket #16 work.

## Scope

This validates the local #1 capability on macOS arm64. It is not evidence for
Cloudflare, device trust, automatic reconnect, four-platform release support,
or an arbitrary Herdr version. The native client handles native protocol
negotiation; the Relay's supported executable baseline remains 0.9.3.
