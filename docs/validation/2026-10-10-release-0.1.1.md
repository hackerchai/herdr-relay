## Operating boundaries

The native queue bound requires `herdr 0.9.3-custom.relay-control-bound-1` as the
server for new sessions. Existing official servers must be replaced/restarted
explicitly; installing Relay alone cannot add the bound. It caps each client's
pending reliable-control lane at 256 messages and 67,108,880 allocated bytes,
with one additional frame potentially in the writer. This is not a process RSS
limit or an upstream-official release. See the [patch](../../patches/herdr/README.md).

GitHub Free rejected private-repository branch protection with HTTP 403. CI and
publication gates are active; the platform cannot enforce required checks on
ordinary PR merges without a supported plan. Visibility remains private.
[Install](../install.md), [self-host](../self-hosting.md),
[operations](../operations.md) and [release/recovery](../releasing.md) are the
operator handoff. Service maintenance is best effort without an SLA.
