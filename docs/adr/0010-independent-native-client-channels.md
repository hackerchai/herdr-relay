# ADR-0010：每次远程 attach 使用独立 native client 通道

日期：2026-10-09；更新：2026-10-10。状态：独立通道已进入候选实现；同实例并发部分被 [ADR-0012](0012-single-active-client-per-target.md) 取代。受控云端和跨平台路径已有[验证](../validation/2026-10-10-candidates.md)，上游可靠控制队列仍阻塞全链路资源验收。

## 背景与依据

原需求 R22–R27 曾要求设备角色可交换、多实例共享和多客户端并发；最新要求保留前两项，并将同实例访问改为独占。Herdr 0.9.3 的 accept 循环为每条 native socket 连接分配独立 client ID；本轮隔离实验验证了两个协议端点接入、分别输入、共同接收更新以及断开隔离。证据见 [兼容性报告](../herdr-compatibility.md)。

## 决策

每次 attach 具有独立的 `channel_id`、端点加密连接和主机 native client socket。主机后台服务复用设备身份、授权数据库和控制连接；数据通道彼此隔离。Herdr 继续处理客户端视图、输入与共享 PTY 尺寸的原生规则。

同一共享目标同时只有一个活动数据通道，由目标 Durable Object 路由；该通道两端各建一条入站 WSS。不同目标可并行，后续 attach 使用全新的独立通道。首先采用易于限制和清理的独立连接，后续是否复用物理 WebSocket 由实测决定。

## 影响

- 一个客户端退出、重连或被撤销，仅关闭相应 socket 与通道。
- 停止某个共享目标时，关闭该目标全部通道；撤销设备时，关闭其对本机全部目标的通道。
- 独占在 Relay attach 准入时执行，不通过合并多个客户端输入来实现；不改写 Herdr 的原生 PTY 尺寸规则，也不承诺控制绕过 Relay 的本机直连。
- 共享目标 ID 长期稳定；进程重启和网络重连使用新通道、代次与握手，旧字节不得续传。
- 独立 WSS 增加连接数，默认并发配额与 Cloudflare 成本需要实际测量。
