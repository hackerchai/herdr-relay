# ADR-0004：第一版交付 CLI 与 Cloudflare Relay

日期：2026-10-09；更新：2026-10-10。状态：已确认；CLI、用户服务、受控云部署和四平台候选已具备，完整发布仍受[验收与维护者输入](../release-readiness.md)阻塞。

## 背景

原设计将最终产品描述为 Herdr 薄插件配合独立 Rust 程序，并提出从本机适配到插件包装的分阶段开发顺序。首个可发布版本的范围需要单独确定。

## 决策及依据

需求访谈 Q3，用户明确回答：“可用 cli 和 cloudflare 远端 relay 这是第一个版本的”。

1. 第一版交付可用的 Rust CLI 和 TypeScript Cloudflare Worker/DO Relay。
2. 用户通过 CLI 共享指定 Herdr 实例、配对设备、管理访问并启动原生客户端连接。
3. Herdr 薄插件留到后续版本。

## 影响

- 首版的配对、状态、共享启停和设备撤销需要 CLI 入口。
- 首版验收覆盖实际远程使用所需的身份认证、端到端加密、授权、断线与流控行为。
- 默认共享托管、免注册、支持自建和全部开源的既有决定继续适用。
- 两端均覆盖 macOS Apple Silicon、macOS Intel、Linux x86_64 和 Linux arm64。
- 发布材料包含本机二进制、CLI 使用说明和 Cloudflare 自建部署说明。
- 插件菜单、插件 manifest、插件拉起外部终端不作为首版交付要求。
- 后续 Q11 已确认支持后台用户服务的安装、启动、停止和状态命令，并保留前台模式；当前登录自启需显式启用，退出登录及开机未登录的支持范围仍待 #19。

## 后续

首版基础能力可供后续薄插件调用，当前 CLI 契约见 [README](../../README.md)。产品长期方向中的插件集成不改变此处的首版边界。

完整需求与访谈记录见 [REQUIREMENTS.md](../../REQUIREMENTS.md)。
