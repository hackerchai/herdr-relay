# ADR-0009：默认 Relay 公开免费，并设资源配额

日期：2026-10-09；更新：2026-10-10。状态：已确认；带配额的受控测试 Worker 已部署，默认公开免费服务尚未启用。

## 背景

默认 Relay 服务共享托管、免注册，支持开源自建。需要明确默认服务的开放范围和使用者是否需要付费。

## 决策及依据

Q14 用户选择：“公开免费：任何人可通过 CLI 使用，服务设合理资源配额”。

1. 默认服务公开提供，任何人可通过 CLI 使用，无需账号或邀请码。
2. 使用者无需付费；首版不引入付费或订阅流程。
3. 服务设置资源配额，具体数值和策略在技术及运营设计中确定。

## 影响

- 公开准入仍需设备认证、配对和发布方授权，不能通过公开 Relay 任意访问其他设备。
- 需限制连接、消息、队列及总体资源，并设计免注册场景的配额执行和滥用处理。
- 达到配额时需要明确的错误或限流结果。
- 免费面向使用者；运营资源预算和费用承担方仍需明确。
- 自建路径继续适用，不能依赖默认服务的收费或账号系统才能完成核心连接流程。

## 尚未决定
