# ADR-0007：导入一次性配对串即可获得设备授权

日期：2026-10-09；更新：2026-10-10。状态：已确认；密码学与事务方案由 [ADR-0011](0011-endpoint-tls-and-pairing.md) 细化，配对已有受控云端与跨平台候选验证。

## 背景

设备免注册接入，访问权限由发布方本地管理。需要确定另一设备导入配对信息后，是否还必须等待发布方二次确认。

## 决策及依据

Q10 用户选择：“A 生成一次性配对串；B 导入即获得授权，无需 A 再次确认”。

Q15 补充确认：兑换时要求 A 的 Relay 后台服务在线，无需 A 人工操作，Herdr 实例可以离线。

1. 发布方 A 主动生成一次性配对串。
2. B 成功导入并完成协议验证、兑换后，即获得访问 A 的设备级授权。
3. A 无需再次批准该次配对；授权覆盖其当前及未来全部已共享实例，反向授权仍独立。
4. 兑换时 A 的 Relay 后台服务必须在线，Herdr 实例不必在线；A 服务离线时不能宣告配对已成功。

## 影响

- 配对串代表一次授予访问权的能力，应限制使用次数与有效期。
- 兑换成功必须绑定到接收方设备身份；同一串不能再为其他设备建立授权。
- 协议仍需认证发布方身份和密钥；单纯交换普通 token 不足以证明端到端身份验证成立。
- 无效、过期及已用配对串应有明确结果，并处理重复请求和并发兑换。
- 保存的设备授权不依赖生成配对串的终端持续打开。
