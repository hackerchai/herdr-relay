# ADR-0012：同一实例只允许一个活动 Relay 客户端

日期：2026-10-10。状态：已接受的产品修正；主机 inode 锁与 Room 独占租约已实现，已有竞争、释放及[四平台候选恢复记录](../validation/2026-10-10-candidates.md)，完整故障组合验收仍未完成。部分取代 [ADR-0005](0005-device-roles-and-concurrent-clients.md) 和 [ADR-0010](0010-independent-native-client-channels.md)。

用户在确认任务拆分时明确：“不要多人操作一个实例这是不可以的，修改一下，其他都ok”。因此每个共享 Herdr 实例同时最多一个活动 Relay 客户端；同一设备的第二次连接也受限制。多台设备仍可获得授权并先后使用，同设备多实例发布、不同实例并行访问及设备双向角色保持不变。上游 Herdr 支持多个 native client 是兼容性事实，不再作为本产品允许同时操作的依据。

对应工程选择是拒绝后来连接，返回 `TARGET_BUSY`，不抢占已有连接，也不排队执行输入。默认托管和自建执行同一约束，不能以调整配额放开。占用按实际实例执行，不能通过重复共享配置或别名绕过；授权成功并不保证实例当前空闲。

主机与目标 Room DO 分别原子预留唯一占用，待建立通道也占位；占用绑定通道及运行代次。失败、退出、撤销、重启和租约到期必须先关闭旧通道或确保旧代次不能传输，再幂等释放占用。旧清理事件不能清掉新占用；休眠唤醒不得丢失占用。网络恢复可有限等待自身旧通道清理，再以新通道重新 attach；目标已被另一连接占用则报忙结束，不自动接管。

独占范围是本产品管理的 Relay 连接。直接使用 Herdr 本机 socket 的客户端不受 Relay 控制，本决策不承诺阻止这种绕过访问。不同目标的资源隔离、撤销和自动恢复仍按原需求执行。

当前最小实现将原生 socket inode 锁放在主机，将独占租约放在 Room DO；加密 WebSocket 路由暂由 DeviceRelay 承担，并在每次转发前验证同一租约代次和到期时间。实现边界见[协议记录](../../protocol/access-v1.md)，验收见[远端原生连接](../validation/2026-10-10-remote-native.md)。
