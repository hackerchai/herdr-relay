# ADR-0003：免注册设备配对与主机本地授权管理

日期：2026-10-09；更新：2026-10-10。状态：已确认；设备身份、配对和本地主机授权已实现并有[候选验证](../validation/2026-10-10-candidates.md)。

## 背景

默认 Relay 服务由多个用户共享，并提供开源自建路径。需要决定用户首次接入是否依赖注册登录，以及谁管理访问 Herdr 的设备授权。

## 决策及依据

需求访谈 Q2，用户选择：“免注册：通过设备身份和配对使用，在自己的主机上管理授权设备”。

1. 默认共享服务采用免注册流程，不要求用户先创建或登录账号。
2. 通过设备身份和配对建立访问资格。
3. 用户在自己的主机上管理授权设备。

## 影响

- 首版无须设计账号注册、登录、密码找回或 OAuth 登录流程。
- 配对必须让端点验证设备身份，主机必须验证访问授权。
- Relay 接入凭据仍需单独设计发放、有效期与撤销，不能用房间 ID 代替。
- 不同使用者的隔离必须建立在设备、目标和授权验证上，不能假定已有云端账号系统。
- 用户应能在主机本地查看和撤销设备；后续 [ADR-0004](0004-cli-and-cloudflare-first-release.md) 确定首版通过 CLI 提供。
- 密钥丢失、主机重装等恢复方式需要另行规定。

## 尚未决定

本决策当时未选择的配对有效期、身份粒度、密钥保存与恢复，已由 [ADR-0011](0011-endpoint-tls-and-pairing.md) 细化。设备签名准入与全站资源限制见[接入协议](../../protocol/access-v1.md)和[全站准入验证](../validation/2026-10-10-admission.md)；生产运营参数仍待发布决定。

后续 [ADR-0007](0007-single-use-pairing-grant.md) 确定首次配对采用一次性配对串，导入即可授权，无需发布方再次确认。

本决策不选择密码学协议或具体实现库。完整访谈记录见 [REQUIREMENTS.md](../../REQUIREMENTS.md)。
